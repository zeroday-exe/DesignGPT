# DesignGPT
Welcome to DesignGPT👋 The best UI/UX Frontend Skill in the World.

## What is DesignGPT
DesignGPT is a Skill for your Ai Agent. Supported are: Claude Code, Codex and any other Agent that supports Skills.
DesignGPT is in a Nutshell a Collection of Websites that have a good UI/UX design, that takes this Websites as Inspiration for design.

## Usage
As you maybe noticed the skill has a tutorial to use it so:
At first download the DesignGPT.md from this GitHub Repository,
after this your add this .md file into your folder or just simply add it.
Now you just need to restart your agent and then you have to add following command in your Chat for Codex:

```bash
$designgpt
```

and for Claude Code use /designgpt.
